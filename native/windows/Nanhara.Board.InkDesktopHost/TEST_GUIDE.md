# 南荒白板多页书写预览 0.2.0-alpha.10

此包从已经通过目标触摸屏验证的 `InkDesktopHost + DirectComposition` 原生书写链路
开始建设正式版，但仍是未签名的产品界面预览，不替换公开版 0.1.2，也不读取或保存
公开版数据。

## 本轮界面与交互验收

1. 解压后运行 EXE，程序应直接显示白板，不出现初始化错误。
2. 宽屏窗口应恢复旧正式版的“深松绿顶栏 + 左侧页面栏 + 中央独立画布”结构；窗口
   收窄到 1120 逻辑像素以下时，页面栏应自动收起，“上一页 / 下一页”移到画布上方，
   画布和工具不能被挤出屏幕。
3. 工具坞分成“颜色、笔触、操作”三组。按钮在 100% 缩放下不小于 50×58 逻辑像素，
   手指点击不应误触相邻工具。
4. 初始画布必须是青黑板 `#274021`。深色背景的四支笔应为粉白 `#F6F1E2`、朱砂粉
   `#F6A07F`、粉黄 `#E7D37E`、粉蓝 `#80C4C6`；实际墨迹必须与色块一致。
5. 依次选择细、中、粗三档并画线，实际宽度应明显变化；点击颜色或粗细应自动退出
   橡皮模式并返回画笔。
6. 点击“背景”应在当前按钮上方出现五项：青黑板、灰黑板、暖纸、柔白、浅网格。
   切到浅色背景后，四支笔应自动变为墨黑 `#1B1B1F`、朱砂 `#A63C26`、松绿
   `#173B34`、青蓝 `#3F666D`；切回深色背景后恢复粉笔配色。切换背景不得卡住画布，
   也不得改变已有笔迹的颜色。
7. 橡皮选中时应显示明确的朱砂激活态。擦掉几笔后点撤销，被擦笔迹应按原位置、颜色
   和粗细恢复。
8. 空白画布上的撤销和清空应呈不可用状态。有笔迹时点清空必须先出现确认框，默认焦点
   为“不清空”；确认清空后仍可点撤销恢复。
9. 分别从普通窗口和最大化窗口进入全屏。触碰画布或工具按钮后，分别用底部“退出全屏”、
   `Esc` 和 `F11` 退出，确认恢复原来的窗口位置和最大化状态。

## 多页与关闭验收

1. 第一页写 A。点左栏“＋ 新建空白页”加入第二页，写 B。点底栏“＋ 新页”加入第三页，
   写 C。逐页往返确认三页各自保留笔迹，且空白新页没有带入上页内容。
2. 在第二页擦除并撤销，再清空并撤销。确认只改变第二页。翻回第一页后按
   `Ctrl+Z` 只撤销第一页最后一笔。
3. 按住笔尖时用键盘请求换页，确认提示抬笔且不切走当前页。连续测试抬笔与点击新页
   几乎同时发生的情况，最后一笔应留在原页。换成橡皮重复操作，确认撤销把笔迹恢复在
   被擦除的那一页。有实体橡皮端的触控笔也要测试，确认擦除后仍能翻页。
4. 退回窗口后点关闭，或在全屏中按 `Alt+F4`。在确认框选择取消时保留当前页与笔迹；
   确认后进程应退出。

## 防眩观察

1. 在客户实际照明下依次比较青黑板、灰黑板、暖纸和柔白；青黑板与灰黑板应明显降低
   屏幕自发光的刺眼感，不能出现软件绘制的高光、渐变或大面积亮纹。
2. 背景只能降低亮度和视觉疲劳，不能消除玻璃对灯具、窗户的镜面反射。若关掉画布
   亮色后仍能清楚看到灯具倒影，应继续检查大屏的防眩玻璃/贴膜、安装角度与亮度设置。

## 原生书写回归

1. 全屏后，在左、中、右三列各轻点 5 次、各画 3 条折线，再快速写 3 遍“走”。
2. 任一区域都不能出现额外连线、落笔跳点或明显延迟；与同屏 Windows 画图比较时，
   可见墨迹仍应保持在一个 60Hz 帧内。
3. 底栏工具切换、按钮重绘和清空确认不能阻塞正在书写的原生 InkPresenter 线程。

## 当前边界

页面与笔迹只保留到本次运行结束，关闭有笔迹的白板时会提示确认。退出 Windows 或
强行结束进程也会结束本次运行。背景图片、本地保存、
欢迎屏、PPT/PDF/图片导入和签名安装器仍待接入。

## 快捷键

- `Ctrl+Z`：撤销上一步书写、擦除或清空
- `F11`：切换全屏
- `Esc`：退出全屏
- `Ctrl+Enter`：新增空白页
- `Ctrl+PageUp` / `Ctrl+PageDown`：上一页 / 下一页
- `Alt+F4`：关闭白板
